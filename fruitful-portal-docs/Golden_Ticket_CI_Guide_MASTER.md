## 1. Brand foundation

### 1.1 Story & mission
Fruitful is a kiosk-based coffee, smoothie and pannekoek portal built on a radical menu doctrine (McDonald's-style 90% cut: 8 lines, no sizes, one spec per SKU) and a purpose engine: **the Banimal Giving Loop**. Every purchase triggers one fresh pannekoek given to a child in need the same day via the daily drop. The 10th menu slot is not a product — it is **The Child Ticker™**, the live counter that makes the giving visible.

### 1.2 Values
Positivity · Optimism · Creative. Ground-truth optimism: "The Lion Sees You." Pretoria / Silverton Hub roots. Dignified hope — never pity.

### 1.3 Voice
- Warm, confident, plain-language; one message per surface.
- The giving loop is stated as fact, not marketing float: "Every item you buy = 1 fresh pancake to a child in need today."
- Zero-waste doctrine in tone too: no filler, no sizes, no small print games.

### 2.2 Logo mark ("f" tile)
- Red rounded square (#E63946), white italic bold lowercase **"f"**, rounded-corner tile.
- Corner radius: 22–25% of tile width (rounded geometry rule).
- Min size: print 8 mm · screen 32 px.
- Never recolor the tile to teal/amber; never rotate; never add effects (shadows, gradients).

### 2.3 Lockups
1. **Tile + FRUITFUL** (default, horizontal; tile left of wordmark)
2. **FRUITFUL — BANIMAL GIVING LOOP** (packaging brand line, top of every panel)
3. **FRUITFUL + tagline** (hero surfaces)

### 2.4 Do / Don't
| Do | Don't |
|---|---|
| Use the tile + wordmark lockups as supplied | Stretch, squash, rotate, or outline the mark |
| Keep clearspace clean | Place on busy photography without a scrim |
| Use approved colours only | Use the historical teal #0FB5A6 anywhere |

> PANTONE values are closest-match references for quoting; confirm with your print partner before ordering.

### 3.2 Proportion rule (60/30/10)
- **60%** neutrals (Light / Slate-900 space)
- **30%** Teal (structure, bands, active states)
- **10%** Red + Amber (CTAs, badges, giving accents — Red and Amber never fight; Red leads, Amber warms)

### 3.3 Accessibility (computed contrast)
| Pair | Ratio | Verdict |
|---|---|---|
| Slate-900 on Light | ≈ 17:1 | AAA — body text safe |
| Amber on Slate-900 | ≈ 10:1 | AAA — badges on dark safe |
| White on Red | ≈ 4.2:1 | AA large text only — never small body text on red |
| White on Teal / Teal on White | ≈ 2.5:1 | Bands & large display only — body text on teal uses Slate-900 |
| White on Amber | ≈ 1.7:1 | **Never** — use Slate-900 text on amber |

## 5. Layout, grid & radii

### 5.1 Panel anatomy (all box sizes) — locked
```
┌─────────────────────────────────────────┐
│  FRUITFUL™ — BANIMAL GIVING LOOP™        │  brand line (top, teal or slate)
│            N PANNEKOEK                    │  header (bold italic caps)
│     [ child-in-need illustration ]        │  hero motif (warm, hopeful)
│  Every item you buy = 1 fresh pancake    │  tagline band (teal #47B3A8)
│  to a child in need today™               │
│  ⭐ THIS PACK FEEDS N CHILDREN TODAY™    │  badge (amber)
│  FNSKU • contains egg • fruitful.co      │  footer (Fira Code, small)
└─────────────────────────────────────────┘
```
Outer carton adds: **"12 × PANC-12 · 144 PANNEKOEK"**, **MADE IN SOUTH AFRICA**, blank FNSKU/barcode label panel, stacking arrows, weight line (~18 kg).

### 5.2 Grid
- 12-column grid on all panels; 8px base spacing unit (4/8/16/24/40/80/120).
- Safe area: 6 mm inside the die-cut line for print; 24 px inside frame for screen.
- Header block occupies the top 18–20% of panel height; tagline band sits at ~70%; footer at ~92%.

### 5.3 Radii (rounded geometry)
- Packaging: consistent large corner radii on panels and badges (badge ≈ 50% of its height = pill).
- Kiosk UI: 24–120 px scale (buttons 24, cards 40, modals 120).
- Logo tile: 22–25% radius.

## 10. The Banimal Giving Loop™ (the engine)

| Rule | Value |
|---|---|
| Trigger | Every item sold — coffee +1 · smoothie +1 · single +1 · 6-box +6 · 12-pack +12 |

## 12. Tool implementation — Canva · Figma · Illustrator

### 12.1 Canva (brand kit)
1. **Brand kit → colours** — add the five tokens: #47B3A8, #E63946, #FFB703, #0F172A, #F8FAFC.
2. **Brand kit → fonts** — set **Inter** as the default font; for mono labels use **Space Mono** or **IBM Plex Mono** (Fira Code is not in Canva).
3. **Uploads → brand folder** — logo tile, wordmark lockups, child-in-need motif, die-cut templates.
4. Build from the packaging template: duplicate the saved panel layout, swap text per SKU (N PANNEKOEK / N children / FNSKU footer).
5. Export: print panels at **300 dpi, CMYK, PDF** with 3 mm bleed; screen graphics at 2× (retina) PNG.

### 12.2 Figma (design system)
1. Create a **Design System file** with **colour styles** (5 tokens + emerald live-dot) and **text styles** (Display / H1 / H2 / Body / Mono per §4.1).
2. **Typography** — Inter and Fira Code are both available via Google Fonts in Figma.
3. Set **variables** (primitive → semantic: `brand/teal`, `text/primary`, `giving/amber`, `live/dot`) so dark/light modes and print swaps stay consistent.
4. Build components: `panel-header`, `tagline-band`, `giving-badge`, `footer-mono`, `child-motif`; compose the die-cut nets from them.
5. Export: PNG 2× for review; SVG for icons/logo; PDF for print handoff.

### 12.3 Illustrator (print production)
1. **Swatches** — create global swatches: Teal #47B3A8 (CMYK 60,0,6,30), Red #E63946 (0,75,70,10), Amber #FFB703 (0,28,99,0), Slate-900 (64,45,0,84), Light (2,1,0,1).
2. **Paragraph/character styles** — FRUITFUL Bold Italic Caps (Inter 700–900, tracking −30), Body (Inter 400), Mono Label (Fira Code; fallback IBM Plex Mono / Space Mono).
3. **Templates** — open the DIECUT PDFs (single / 6pk / 12pk / outer), keep the die lines on a locked layer, art on top, 3 mm bleed, 6 mm safe area.
4. **Marks** — apply ™ on first prominent use; the © footer line is a standard text snippet; NO ® until the attorney confirms.
5. Preflight: fonts embedded, CMYK, bleed + crop marks, barcode/FNSKU panel left blank for the label step.

### 12.4 Export matrix
| Use | Format | Spec |
|---|---|---|
| Print packaging | PDF/X-1a or PDF/X-4 | CMYK, 300 dpi, 3 mm bleed, embedded fonts |
| Screen (site, ticker) | PNG / WebP | RGB, 2× (retina) |
| Logo & icons | SVG | vector, no rasterization |
| Review renders | PNG | 1×/2×, RGB |
