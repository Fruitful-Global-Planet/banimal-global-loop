## 1. The invention (what is being claimed)

**Title:** *Footwear-integrated floor-hygiene system for food-service kiosk environments*

A footwear system for retail/food-service staff where the shoe **looks like standard work footwear**, but the soles carry **replaceable cleaning pads**, turning every staff step into a floor wipe — combined with an **integrated wash/dry dock** and **automated compliance logging**.

### Claim set (combination — the value is in the system, not the sole)
1. **C1 — Footwear:** staff shoe with hidden, replaceable cleaning-pad soles (microfibre or equivalent), normal exterior profile, food-grade, anti-slip-certified materials.
2. **C2 — Dock:** an integrated wash/dry dock (kiosk plinth / floor base) that cleans and dries the pads between shifts, reusing the kiosk's water/sump infrastructure.
3. **C3 — Compliance:** pads tagged (NFC/RFID); dock logs each pad's wash cycle, step count, and change-out to an automated compliance logbook (store telemetry → audit trail, uneditable).
4. **C4 — Triggers:** cleaning activity activated by store data — till output (order volume), weather conditions, time windows — the same trigger engine that runs the kiosk's vented-floor suction system.
5. **C5 — Use class:** deployment in the mobile/retail kiosk and food-service portal classification, in combination with a vented, suction-capable floor base ("Floor Wizard", companion disclosure FSP-FW-001).

## 2. Prior-art check (honest — read this twice before filing)

The **bare "sole as mop" concept is NOT novel** and prior art exists at three levels:

| Level | Prior art | Status |
|---|---|---|
| Passive | Microfiber "mop slippers" / floor-polishing slippers (consumer products) | PUBLISHED / sold |
| Active | Vacuum slippers (micro-suction soles with heel collection chambers) | PROTOTYPED / publicised |
| Smart | Motorized rotating-sole self-cleaning shoe | CONCEPT documented |
| Industrial | Cleanroom fleece overshoes (dust pickup in pharma/electronics) | STANDARD practice |

**Novelty assessment:** individual elements are anticipated. The **combination** (C1–C5: hidden pads + dock + NFC compliance logging + store-telemetry triggers + mobile-kiosk/food-service use class) is not found in the prior art identified — **the system, the data layer, and the use class are the filing angle**, not the shoe.
