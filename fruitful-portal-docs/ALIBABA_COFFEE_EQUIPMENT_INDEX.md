## Recommendation summary
1. **Super-auto route (staff-light, kiosk-first):** Jetinno JL29B ($742–834) or Dazheng Dr GT2 — one-touch, milk carafe, 10-yr/9-yr manufacturers; add Aicksn filter ($50). **~$800–900/kiosk — inside budget.**
2. **Craft route (artisan barista, higher quality):** Itop 2-group ($1,389–1,638) + Jiaozuo Forward grinder ($178) + Aicksn filter ($50). **~$1,620–1,870/kiosk** — slightly over the $1,200 target but the flagship-quality option; Chashimi at $938 + grinder keeps it **~$1,170**.
3. **Space-max route:** Kinghigher all-in-one ($181–262) — extreme budget, built-in grinder; verify duty cycle for 100 cups/day before committing (newer supplier, 1-3 yrs).
4. **Skip:** vending units >$1,700 (Huanor/Guangjiao) unless going fully staffless; note ZA 220V/50Hz must be confirmed with every supplier (several listings show 110V).
