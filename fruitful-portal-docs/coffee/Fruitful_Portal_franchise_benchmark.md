## 2. Financeability Advantages

| Factor | Fruitful Portal | Why it finances better |
|--------|-----------------|------------------------|
| **Asset is movable security** | Portal can be repossessed & redeployed | Lower loss-given-default → banks lend more readily |
| **Defined unit cost** | Documented PI (R130,929) & quote (R111,500) | Clear, evidenced asset value for the bank |
| **Multiple finance modes** | 24/36/48/60-month, rental, RTO, subscription | Matches buyer cash profile; widens approval pool |
| **Residual value** | Mobile asset retains resale value | Supports rental/RTO residual structures |
| **VAT mechanics** | Import VAT reclaimable (VAT-registered) | Improves effective cost basis |
| **Lower entry deposit** | Smaller capital base than full kiosk fit-out | Easier affordability/break-even pass |

Affordability and break-even formulas: see `Fruitful_Portal_finance_model.md` §9 (`T_BE`, `GPP`, `LTV`).

## 3. Mobility Advantages
