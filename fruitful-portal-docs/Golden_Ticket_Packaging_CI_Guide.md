## 1. Purpose

One visual standard for every physical touchpoint of the giving-loop pancake system: the **single roll box, the 6-piece box, the 12-pack case, the outer shipping carton**, and the pallet build. Everything a customer or a DC worker touches speaks one language: **Positivity. Optimism. Creative.** — the brand values from the CI guide.

## 4. Typography

| Role | Font | Style |
|---|---|---|
| Headlines / brand line | **Inter** (700–900) | **bold, italic, uppercase**, tight tracking |
| Body / info | Inter (400–600) | clean, generous leading |
| Labels / codes / barcode text | **Fira Code** (mono) | FNSKU, batch, "PANC-12", allergen |

## 5. Design principles

1. **Rounded geometry** — large radii (box panels use consistent corner radii; kiosk UI uses 24–120px scale)
2. **Whitespace first** — no clutter; one message per panel
3. **Terminal-glass details** — subtle mono labels, live-status dots (the 9-second pulse lives in the ticker, not the box)
4. **Restrained** — never add elements the user did not request (no third-party logos, no fake badges, no QR unless specified)

## 9. Imagery style

- **Hero motif:** child-in-need illustration — happy child with a fresh pancake; warm, hopeful, dignified (never pity). Template reference: "Child in Need" artwork.
- **Photography:** lifestyle (kiosk, hands with pancakes, coffee hero), warm natural light, real people.
- **Fruitful asset family:** Fruitful HighRes logo, thank-you card, coffee hero, signal artwork — all in the same teal/red/amber/cream family.
- **Prohibited:** sad/starving imagery, pity aesthetics, over-saturation, unrelated memes.

## 10. Do / Don't

| Do | Don't |
|---|---|
| Use #47B3A8 teal as the anchor | Use #0FB5A6 or off-palette teals |
| Bold italic caps for headers | Light weights for headers |
| 1-for-1 giving claims only (by piece) | Claim "15.01%" or numerology on packaging |
| Blank label panels for FNSKU/barcode | Print fake barcodes/certifications |
| Allergen line (contains egg) | Omit allergen / nutrition claims |
| MADE IN SOUTH AFRICA on the outer | Use third-party logos (Paystack, Amazon etc.) |
